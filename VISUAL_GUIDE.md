### WORKFLOW EXAMPLE

#### Simple Editing (3 minutes)
```
1. RECORD
   ↓
   Click "Start Recording"
   Speak naturally
   Click "Stop Recording"
   
2. PREVIEW
   ↓
   Click "Play"
   Listen to recording
   
3. ENHANCE
   ↓
   Click "Noise Reduction"
   Click "Auto Normalize"
   
4. EXPORT
   ↓
   Select "MP3"
   Click "Export MP3"
   ✓ File downloaded
```

#### Advanced Editing (5-10 minutes)
```
1. RECORD & TRANSCRIBE
   ↓
   Recording completes
   Auto-transcription appears
   
2. TRIM SECTIONS
   ↓
   Set trim start: 2 seconds
   Set trim end: 1:45
   Click "Apply Trim"
   
3. ADD VOICE EFFECTS
   ↓
   Select "Deep Voice" filter
   Adjust pitch to +5
   Set speed to 1.5x
   
4. ENHANCE AUDIO
   ↓
   Click "Noise Reduction"
   Click "Compression"
   
5. ADD SUBTITLES
   ↓
   Subtitles auto-generate
   Edit any subtitle text
   Click "Export SRT"
   
6. CREATE SEGMENTS
   ↓
   Add cuts at 0:15, 0:30
   Review cut points
   
7. FINAL EXPORT
   ↓
   Select "MP3" format
   Click "Export MP3"
   ✓ Audio ready for use
   ✓ Subtitles ready for video editor
```

## KEYBOARD SHORTCUTS

| Key | Action |
|-----|--------|
| Space | Play/Pause |
| Ctrl+S | Export/Save |
| ← → | Seek ±5 seconds |
| ↑ ↓ | Adjust volume |
| T | Toggle trim mode |
| F | Apply current filter |

## COLOR CODING

### Waveform Colors
- 🔵 **Blue** = Audio content
- ⚫ **Gray** = Silence/empty
- 🟢 **Green** = Playhead position

### Button States
- 🔵 **Blue** = Active action
- ⚪ **Gray** = Inactive/disabled
- 🔴 **Red** = Delete/remove

### Status Colors
- 🟢 **Green** = Success/applied
- 🔴 **Red** = Error/failed
- 🟡 **Yellow** = Processing/warning
